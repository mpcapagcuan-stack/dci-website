# DCI Website

This repository contains a simple multi-page website for the Department of Computing & Informatics (DCI) for a lab assignment. It demonstrates HTML structure, navigation, media embedding, forms, tables, and external CSS.

Files included:
- index.html — Home / About page
- programs.html — Programs & Facilities page (BSIT, BSCS, comparison table)
- inquiry.html — Inquiry / Contact form
- css/style.css — External stylesheet demonstrating required CSS properties
- images/ — placeholder SVG images (logo, faculty, program images)
- media/ — placeholder instructions for adding media files

Replace the placeholder images in `images/` and add `media/promo-video.mp4` and `media/anthem.mp3` if you want local media.

To view locally, clone the repo and open `index.html` in your browser.
